Instrukcja wdrożenia — Środowisko Staging

Dokument opisuje krok po kroku uruchomienie Portalu Klienta B2B na środowisku staging.portal-b2b.euvic.pl.

Wymagane uprawnienia: rola Menedżer lub Właściciel projektu.

1. Wymagania wstępne

  • Docker 26+ oraz docker compose
  • Dostęp do rejestru obrazów registry.euvic.pl
  • Sekret DB_PASSWORD dodany w Ustawienia → Dostępy zewnętrzne

2. Zmienne środowiskowe

ZmiennaPrzykładOpis
BASE_URLhttps://staging.portal-b2b…Adres publiczny portalu
DB_HOSTdb-staging.internalHost bazy PostgreSQL
PAYMENTS_KEY(sekret)Klucz bramki płatności

3. Uruchomienie

git checkout release/1.8
docker compose -f compose.staging.yml up -d

Po starcie sprawdź GET /health — powinno zwrócić 200 OK.
