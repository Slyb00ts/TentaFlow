Projekty · Project Studio

Kompletny zestaw mockupów modułu „Projekty" — centralna przestrzeń projektu z bazą wiedzy (RAG), testami (manualne / UI / API / jednostkowe / wydajnościowe / bezpieczeństwa pisane przez agentów), dokumentacją, chatem, zadaniami, artefaktami i połączeniem z ML Studio. Zawiera też przeprojektowane, przyjazne UI tworzenia agentów. Motyw i komponenty spójne z tentaflow-core/www. Kliknij ekran, aby otworzyć.
