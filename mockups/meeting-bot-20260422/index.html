Meeting Bot — final mockup

Kompletny re-design aplikacji Meeting Bot jako user-app w nowym języku projektowym. Jednolity header (żadnego REC/Stop — bot dołącza wklejeniem linka), czytelna typografia, natywne web-components z systemu (tf-button, tf-chip, tf-input). Pokazane 7 ekranów pokrywających pełny flow: pusty stan → dołączanie → aktywne spotkanie → podgląd ekranu bota → historia sesji → błąd braku addona → ustawienia.

User app · prawy dolny avatar Join by URL (Teams/Meet/Zoom) Live transcript · speaker diarization AI summary inline Session history + download .txt VNC preview w iframe (nie popup) Spójny header z Chat/Notes/Tłumacz

📐 Uwagi implementacyjne

  • Header: ten sam wzorzec co Chat/Notes — title-ico + h1 + sub po lewej, akcje po prawej. Zero custom REC/Stop.
  • Komponenty: przyciski = tf-button (variants: primary/ghost/danger + size sm/lg), chipy = tf-chip (status: success/warn/danger/accent/live), URL input = tf-input z icon="link", selecty w ustawieniach = tf-select, tabs = tf-tabs.
  • Backend (bez zmian): używa istniejących endpointów POST /api/addons/teams-bot/tools/join_meeting, GET /api/meeting-bot/transcripts, GET /api/meeting-bot/sessions/:id/download. Nowe do dodania: GET /api/meeting-bot/sessions (lista dla historii) + GET /api/meeting-bot/sessions/:id/summary (TL;DR z LLM).
  • VNC inline: <iframe src="wss://..."> w ekranie 4 zamiast window.open() — bez problemu mixed-content bo cały trafik przez mesh QUIC.
  • Scroll-preserve: logika z obecnego MeetingBot.js (wasAtTop + prevScrollHeight delta) zostaje. Działa dobrze, nie trzeba ruszać.
  • Speaker diarization: kolor = hash(nazwa) → HSL (już działa). Avatar 36×36 z gradientem per-speaker. Badge enrolled/temp przy meta.
  • AI insights row: inline w transcript feed (nie osobny panel) — wizualnie wyróżniony dashed border + gradient tło, żeby było jasne że to AI a nie człowiek.
  • Error state (screen 6): pokazuje się gdy /api/services/deployed nie zawiera agents/teams-bot. CTA do Services kieruje do deploy wizard.
  • Mobile/responsive: @ <1200px side panel przechodzi pod transcript (stack), historia zostaje single-column z list → detail toggle.
  • Brak REC/Stop: dołączenie = wklejenie linka + Enter. Opuszczenie = przycisk "Opuść" w headerze lub user wychodzi z aplikacji (bot i tak zostaje w meetingu aż do timeoutu sesji lub eksplicit leave).
