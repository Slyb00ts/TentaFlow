Jak działa model w modelu uprawnień

Modele są zasobami systemowymi — owner to manual (admin) lub system, nigdy addon. Consumer to addon który chce wywoływać ten model — musi w swoim manifeście mieć [[uses_model]] id = "yolov8-pose-v3". Visibility kontroluje co się dzieje po deklaracji: restricted ⇒ pending → admin zatwierdza tutaj; public ⇒ auto-grant.
