Konta agentów CLI — mockupy do akceptacji

Plan: docs/agent-accounts-global-user-plan.md. Każdy ekran jest osadzony w powłoce aplikacji i ma u góry pasek „Gdzie w aplikacji” z drogą dojścia. Żółte kółka z numerem pokazują, co otwiera następny ekran.

Droga administratora: A01 → A02 → A03/A04, N01. Droga użytkownika: U01 → A02 albo C01 → A02. Przypisanie konta agentowi: G01. Efekt w pracy: C02.

A01 · Serwisy → zakładka „Konta agentów”
Punkt startowy administratora. Istniejący ekran i istniejąca zakładka; nowa zawartość.
 A02 · Okno logowania (link → kod)
Otwierane z A01, U01 i C01. Rozszerzenie istniejącego okna logowania agenta.
 A03 · Okno „Konto agenta” — Przegląd
Otwierane kliknięciem wiersza w A01. Istniejące okno, nowa zakładka.
 A04 · Okno „Konto agenta” — Dostęp
Istniejąca zakładka tego samego okna, rozszerzona o grupy.
 N01 · Serwisy → Konta agentów → „Aplikacje na nodach”
Drugi segment tej samej zakładki: gdzie zainstalowano aplikacje CLI.
 U01 · Moje konta → „Aplikacje agentowe”
Istniejący ekran użytkownika, nowa sekcja kart.
 G01 · Agenci → agent → Konfiguracja
Kopia istniejącego ekranu; zmienia się tylko sekcja „Model i generowanie”.
 C01 · Code Studio → konsola: brak konta użytkownika
Kopia istniejącej konsoli; używa wzorca „agent pyta”.
 C02 · Code Studio → konsola: dwa konta w jednym katalogu
Kopia istniejącej konsoli; konto jako chip przy sub-agencie.
