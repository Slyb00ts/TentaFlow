Robots

Redesign aplikacji Robots — lista pokazuje tylko ogólne informacje, a wszystko (kamera, lidar, pełne sterowanie, telemetria) jest w widoku szczegółów. Mockupy v1.

Podział widoków

Lista = RTT, bateria, online/offline, E-STOP/Start, ruch ogólny, Hello. Reszta po wejściu w robota: zakładki Kamera / LiDAR / Sterowanie / Informacje / Log.

Addon bez UI

Addon robota wystawia tylko dane i akcje przez protokół. Całe UI to core'owy moduł Robots. Połączenie automatyczne przez service-tick z backoffem (bez klikania w addonie).

Stylistyka

Komponenty tf-*, paleta TentaFlow (Manrope, dark indigo/violet). Nowe primitywy (np. d-pad, robot-card) trafią później do tf-* jako reużywalne.

R1

Lista robotów

Karty z ogólnym info: status, bateria, RTT + ogólne sterowanie (E-STOP, Start, Hello, d-pad). Wejście w szczegóły.
R2

Szczegóły robota

Nagłówek + KPI + zakładki: Przegląd, Kamera (live), LiDAR 3D (głębia/heatmapa), pełne Sterowanie, Informacje, Log.
R3

Mapa scen

Roboty na mapie 3D budowanej w czasie rzeczywistym; każdy stoi w swojej zlokalizowanej pozycji. Warstwy: voxele / heatmapa / prymitywy.
