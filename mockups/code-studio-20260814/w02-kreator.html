Native domyślny

Zaufane wykonanie lokalne jako użytkownik usługi.
  • Startuje od razu, bez obrazu kontenera
  • Pełny toolchain hosta, bez montowań
  • Kod ma dostęp do hosta — brak izolacji
  • Rozdział ro/rw dotyczy narzędzi, nie komend

Kontener

Pełna izolacja od hosta.
  • Wymuszone profile ro / cow / rw
  • Kontrolowany ruch sieciowy przez bramkę
  • Metadane git niewidoczne dla kodu
  • Pierwszy start dłuższy o pobranie obrazu
Tryb jest niezmienny po założeniu — sesja nie może zacząć się pod jednymi gwarancjami, a skończyć pod innymi.
autonomiczny
tylko lokalnie
Dwie opcje są ukryte, bo w trybie native nie ma czym ich wymusić: autonomiczny uruchamiałby dowolne komendy bez izolacji, a tylko lokalnie wymaga odcięcia trasy sieciowej. Serwer odrzuca obie także wtedy, gdy przyjdą pominięciem UI.
