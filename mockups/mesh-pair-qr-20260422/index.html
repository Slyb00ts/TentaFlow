Format danych w QR kodzie

URI schema parseowany przez aplikację po zeskanowaniu. Typ TEXT (QR v7, ~330 znaków, error correction M):

tentaflow-pair://3e3b459925668f8a4cd29f65cbe7a27c2e4be3c5e0f7b8a50f1c1e0b52a7f01e?pin=421957&host=mainpc&ver=1

Pola: hex node_id (path), pin 6-cyfrowy PIN, host hostname (informacyjnie), ver wersja protokołu QR. Aplikacja skanująca: otwiera ten samego schema handler → automatycznie wykonuje meshPairingStartRequest + meshPairingConfirmRequest w tle.
