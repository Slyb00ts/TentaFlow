Krok 5.1 — Format eksportu (bramkowany: model audio/Whisper)

Dla wytrenowanego Whispera dostępne są silniki ASR. Formaty LLM-only są wyszarzone z powodem.

CT2 / faster-whisper ONNX (onnxruntime) GGUF (whisper.cpp) CoreML HuggingFace NVFP4 (vLLM)

Poziomy kwantyzacji zmieniają się z formatem — poniżej siatka dla aktywnego formatu (CT2 / faster-whisper). Tabela „Poziomy per format" pokazuje warianty każdego formatu.

Krok 5.3 — Deploy

Lokalnie do models/ + TOML
Skopiuj wariant CT2 do models/whisper-pl/, wygeneruj manifest deploy (faster-whisper), zarejestruj jako serwis ASR. Dostępny przez service_request (task „asr").
Zewnętrzny endpoint
Wypchnij do zewnętrznego serwera ASR. Wymaga skonfigurowanego dostępu (Settings → Dostępy zewnętrzne).
# wygenerowany manifest deploy (models/whisper-pl/deploy.toml) name = "whisper-pl" engine = "faster-whisper" task = "asr" language = "pl" base = "whisper-large-v3" model_file = "whisper-pl-int8/" quantization = "int8" eval_wer = 0.049
