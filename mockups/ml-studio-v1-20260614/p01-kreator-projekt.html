Krok 2 — Wybierz typ projektu

Typ określa, co projekt potrafi i jakie będą kolejne kroki. Wybierz jedną kartę — np. Rozpoznawanie obrazu dla wykrywania obiektów na zdjęciach (jak cysterny ADR), albo Fine-tuning LLM dla dotrenowania modelu językowego (jak Guard).

Rozpoznawanie obrazu
Detekcja obiektów / klas na zdjęciach z atrybutami (OCR, klasyfikatory). Kolejny krok → schemat klas i atrybutów. Modele: RF-DETR, OWLv2, Qwen-VL.
Fine-tuning LLM
Dotrenowanie modelu językowego (klasyfikacja, asystent). Kolejny krok → model bazowy + metoda. QLoRA / LoRA / DoRA / Full. Wzór: Guard.
Fine-tuning vision / audio / obraz
Dotrenowanie modeli wizyjnych, mowy (Whisper) lub generacji obrazu (diffusers). Kolejny krok → model bazowy modalności.
ML tabelaryczne + anomalie
AutoML na danych tabelarycznych, klasyfikacja/regresja, wykrywanie anomalii (IsolationForest / PyOD). Kolejny krok → mapowanie kolumn → role.
RAG
Wyszukiwanie i odpowiedzi z cytowaniem na bazie własnego korpusu (HNSW + reranker). Kolejny krok → źródła dokumentów + chunkowanie.
Destylacja
Model-nauczyciel (większy, z serwisu) uczy mniejszego ucznia. Kolejny krok → wybór nauczyciela + ucznia + zbiór promptów.
Co dalej dla typu „Rozpoznawanie obrazu”
Krok 3 · Dane (zdjęcia) Schemat: klasy + atrybuty (OCR, lookup, klasyfikatory) Anotacja → Pre-label modelem → Trening

Gdybyś wybrał „Fine-tuning LLM”, krok 3 prowadziłby do „Model bazowy + metoda treningu (QLoRA…)” zamiast danych zdjęć.
