ML Studio — Przegląd (M1)

Addon ML Studio w globalnym shellu TentaFlow. Lewa kolumna to standardowa nawigacja TentaFlow; wewnętrzna nawigacja modułu (Przegląd / Dane / Anotacja / Trenuj / Fine-tuning / Joby / Modele) odbywa się przez zakładki w detail-header. Ten ekran to pulpit: KPI, ostatnie treningi, modele w serwisie i szybkie skróty.

Jeden moduł

ML, anotacja, dane i fine-tuning w jednym addonie — wspólne zbiory, joby i rejestr modeli.

Silniki + serwis

Treningi odpalane przez flow engine na bundlach Python; inne modele z serwisu pre-oznaczają dane.

Szybki start

Skróty „Nowy trening / Pre-oznacz / Połącz dane” prowadzą wprost do właściwej przestrzeni.
