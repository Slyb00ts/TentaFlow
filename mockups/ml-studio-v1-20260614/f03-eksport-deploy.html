Krok 3 — Deploy

Lokalnie do models/ + TOML
Skopiuj GGUF do models/guard-qlora/, wygeneruj manifest deploy (llama.cpp), zarejestruj w serwisie. Dostępny przez service_request / llm_generate.
Zewnętrzny endpoint
Wypchnij do vLLM / HF Inference Endpoint. Wymaga skonfigurowanego dostępu (Settings → Dostępy zewnętrzne).
# wygenerowany manifest deploy (models/guard-qlora/deploy.toml) name = "guard-qlora" engine = "llama.cpp" model_file = "guard-qlora-Q4_K_M.gguf" quantization = "Q4_K_M" context_size = 2048 task = "prompt-safety-classification"
