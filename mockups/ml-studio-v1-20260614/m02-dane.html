ML Studio — Dane i połączenia (M2)

Wgrywasz pliki (xlsx / csv / parquet) lub podpinasz zewnętrzną bazę, podglądasz dane i w kreatorze mapujesz kolumny na role (feature / label / id / text / prompt / response / timestamp). Dla JSON mapujesz ścieżki. Wynik to znormalizowany zbiór gotowy do treningu.

Upload & bazy

Konektory Rust: calamine (xlsx), csv, parquet/arrow; zewn. bazy przez sqlx (Postgres/MySQL/SQLite).

Mapowanie ról

Każda kolumna dostaje rolę. Schemat zapisany w storage; konektor produkuje parquet/jsonl.

JSON / ścieżki

Zagnieżdżony JSON mapowany przez jsonpath — np. messages[].content → rola text.
