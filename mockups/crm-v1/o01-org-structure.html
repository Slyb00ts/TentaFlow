TentaFlow — Struktura organizacyjna (O1) · FlowBuilder-style

Edytor inspirowany FlowBuilderem: paleta ról po lewej, free-form canvas pośrodku, inspector po prawej. Buduj zależności jak w Flow: przeciągnij rolę z palety na canvas (powstaje stanowisko), połącz port dolny przełożonego z portem górnym podwładnego = relacja raportowania. Linie ciągłe = główny przełożony, kropkowane = drugi (matrix-parent). Sam edytor jest agnostyczny — addony (CRM/Billing/Activity/Calendar) konsumują strukturę przez host fn org.*.

Paleta = role z katalogu

Po lewej kategorie z O2 Katalogu ról (Management/Sales/Technical/External). Drag-drop tworzy nowe stanowisko z tą rolą.

Porty = zależności

Każdy węzeł ma input port (góra) i output port (dół). Drag z output A → input B = B raportuje do A. ⌘+drag = matrix-parent (drugi szef).

Zoom / pan / minimap

Scroll = zoom (30%-200%), drag tła = pan, minimapa pokazuje gdzie jesteś. Autosave w topbar. Undo/redo. Wszystko jak w FlowBuilder.
