Dostęp i klucze API

Zewnętrzne, zgodne z OpenAI API /v1 (chat, embeddings, audio, /v1/models) zabezpieczone kluczami API. Trzy typy klucza, uprawnienia edytowalne z obu stron (od podmiotu i od zasobu) w macierzy identycznej jak uprawnienia funkcji addonów, oraz pełna synchronizacja kluczy i uprawnień przez mesh — ten sam klucz działa identycznie na każdym węźle (A / B / C).

Trzy niezależne osie. (1) Typ klucza — komu klucz odpowiada (user / grupa / ogólny). (2) Uprawnienia do zasobów — model / flow / alias, allow / deny / dziedzicz, edytowalne z obu stron. (3) Egzekwowanie /v1 — default-DENY: nic nie jest dostępne, dopóki nie zostanie jawnie nadane; efektywny dostęp = scope_klucza ∩ uprawnienia_podmiotu.
