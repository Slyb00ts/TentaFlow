Kolejność rozwiązywania: admin → deny usera → allow usera → deny grupy → allow grupy → Domyślne. Na /v1 Domyślne = DENY (nic bez jawnego nadania). Klucz dodatkowo zawęża: efektywny dostęp = scope_klucza ∩ wynik_macierzy.

Macierz: grupy × zasoby · kliknij komórkę aby cyklicznie zmieniać allow → deny → dziedzicz

Kolumny pogrupowane: Modele (usługi lokalne + mesh), Flow (opublikowane), Aliasy (z fallbackami). Tabela przewija się w poziomie przy wielu zasobach.
