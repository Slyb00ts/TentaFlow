tf-pin-input — OTP-style PIN dla mesh pairing

Komponent 6-cyfrowego inputu PIN w stylu 2FA/bluetooth. Auto-advance między polami, paste rozrzuca cyfry po boxach, strzałki + backspace nawigują wstecz. Monospace JetBrains Mono, akcent indigo→violet spójny z resztą systemu. Zastępuje zwykły tf-input w `openConfirmPinModal`.

Specyfikacja komponentu

tag
<tf-pin-input>
attrs
length="6" (default 6)
group-size="3" (split 3+3, separator `·`)
disabled
error (bool — shake + red border)
success (bool — green border)
autofocus
properties
.value — getter/setter (string "454568", bez spacji)
.complete — readonly bool
events
input — każda zmiana (event.detail = { value, complete })
complete — odpalony gdy wpisanych 6/6 cyfr
change — jak complete ale kompatybilny z form
keyboard
0-9 wpisuje + auto-advance do następnego pola
Backspace czyści aktualne, jeśli puste → cofa focus i czyści poprzednie
←/→ nawigacja między polami
Ctrl+V / paste rozrzuca cyfry (strip non-digits, bierze pierwszych length)
Enter emituje submit gdy complete
accessibility
każde pole aria-label="PIN cyfra N z 6",
container role="group" aria-labelledby="…",
inputmode="numeric" + autocomplete="one-time-code" (natywny OTP autofill na iOS/Android)
rozmiary
cell 52×64px, font 28px bold mono, gap 10px, separator 22px
użycie w mesh.js
Zastępuje tf-input w openConfirmPinModal. Walidacja: input.value.length === 6. Bez regex, bez strip — komponent już pilnuje że są to tylko cyfry.
