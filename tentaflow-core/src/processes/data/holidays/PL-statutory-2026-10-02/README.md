# Poland statutory calendar data

This release records the rules known as of 2026-10-02, with local-date coverage [2024-01-01, 2041-01-01). Later dates are projections under reviewed law. The baseline rules have effective_from=2024-01-01 because this is the release coverage floor; it is not their original enactment date. The additional 24 December rule has the actual 2025-02-01 commencement date. Sunday and the Easter offsets 0, 1, 49 and 60 are explicit rules. A Saturday compensatory day remains an owner-entered manual closure.

The complete captured official index and relationship responses are retained with their exact source bytes and digests. Review covered 517 PM regulations, 516 indexed legal bases and the unindexed DU/2026/1215 election text. No applicable extraordinary Art. 1a date was identified in those reviewed records. This claim is limited to the reviewed as-of baseline. New applicable law requires a new reviewed release and publication; existing pins are immutable.

The source manifest retains the original retrieval paths as evidence; these paths are never included as calendar-pin values or used for runtime I/O. Pin authenticity comes from byte-for-byte equality to retained application data, not a client URL or digest.
