@@ pl
CNOT odwraca kubit docelowy wtedy i tylko wtedy, gdy kubit sterujący jest w stanie |1⟩.

Zbuduj bramkę CNOT ze sterowaniem na `q[0]` i celem `q[1]`. Sprawdzana jest cała macierz unitarna 4×4, więc obwód musi działać poprawnie na wszystkich czterech stanach bazowych, nie tylko na |00⟩.

@@ en
CNOT flips the target qubit if and only if the control qubit is in |1⟩.

Build a CNOT with control `q[0]` and target `q[1]`. The whole 4×4 unitary is compared, so the circuit has to be right on all four basis states, not just on |00⟩.
